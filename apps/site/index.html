Core Workflow

围绕真实练习，而不是空泛打卡

v1 的页面和下载入口只承载必要信息；产品能力会优先服务桌面端的离线学习闭环。

句子挖空

用完整句子承载词汇，不把单词从语境里切出来硬背。

翻译提示

保留中文语义线索，让输入答案时更像主动回忆。

输入答案

先打出来，再校对大小写、标点和拼写，比只点选项更扎实。

错题复习

把答错的词和句子沉淀进复习队列，后续接入间隔复习。

内容包

为公开词库、句库和自定义内容预留导入结构，并记录来源与许可证。

学习统计

后续展示练习量、正确率、连续学习天数和薄弱词汇。

Open Source

开源、本地优先、内容来源透明

BestLNG 的第一阶段目标不是云端账号体系，而是在本地桌面环境里完成基础练习。 这意味着学习数据、内容包和复习计划会优先围绕本地可控来设计。

  • 桌面端优先，网页端第一阶段只做发布页和下载入口。
  • 外部内容包必须记录来源和许可证，避免打包版权不明确的数据。
  • 许可证、远程仓库地址和贡献说明会在正式发布前补齐。
